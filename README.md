# Sales Tracker in Google Sheets

## Project Overview
Created a sales tracker using Google Sheets to calculate daily, weekly, and monthly sales totals from retail transaction data.

## Objectives
- Organize raw sales data separately from the summary.
- Calculate sales totals using SUMIFS formulas.
- Use dropdown data validation to maintain consistent sales channel entries.
- Verify calculations using sample data.

## Tools Used
- Google Sheets
- Spreadsheet formulas
- Data validation

## Features
- Daily sales summary
- Weekly sales summary
- Monthly sales summary
- Sales channel dropdown validation

## Files
- `Sales_Tracker.xlsx` — Spreadsheet template and summary.

## Note
The uploaded workbook uses anonymized sample data for demonstration.
